## 0. อ่านไฟล์ดีไซน์ยังไง

- `design/*.dc.html` เป็นไฟล์ของ Claude Design — **เปิดในเบราว์เซอร์ตรง ๆ ไม่ได้** (ต้องใช้ runtime ของ canvas)
  ให้อ่านเป็น "สเปก" แทน:
  - markup + `style="..."` = หน้าตาจริงทุกพิกเซล (สี ระยะ ขนาดฟอนต์ มุมโค้ง เงา)
  - `{{ชื่อ}}` = ค่าที่มาจาก `renderVals()` ในแท็ก `<script type="text/x-dc">` ท้ายไฟล์
  - `<sc-for list="{{x}}" as="it">` = `x.map(it => ...)` · `<sc-if value="{{x}}">` = `{x && ...}`
  - `<dc-import name="StoryCase" idx="1">` = ใช้ component `StoryCase` พร้อม prop `idx=1`
  - `this.state` / `setState` = `useState` ใน React
- ความกว้างดีไซน์ = **1440px** เนื้อหาอยู่ในช่อง `margin-left: 168px; margin-right: 80px` (เว้นที่ให้แถบเมนูซ้าย)
- รูปทั้งหมดอยู่ใน `assets/` แล้ว (path ในไฟล์ดีไซน์ชี้ไปที่ `../assets/...`) → ย้ายไป `frontend/public/` หรือ `src/assets/` ตามที่โปรเจกต์ใช้

### 2.1b พื้นหลังแยกแต่ละ section + หัวข้อไฮไลต์ (อัปเดต 26 ก.ย. ค่ำ)
- ตั้งแต่จอ 2 ลงไป **แต่ละ section เป็นแถบเต็มความกว้าง สลับ 2 สี** ครีม `#F6F2EA` / ขาวนวล `#FFFDF8` + เส้นบางด้านบน `1px solid #E4DCCC` (ลำดับดูในไฟล์ part1–3)
  > ⚠️ **สีชุดนี้ยังชั่วคราว** เจ้าของกำลังเลือกแบบใหม่ที่ "เฟี้ยว" กว่า (ตัวเลือก: พื้นดำสลับครีม + แถบตัวหนังสือวิ่งเอียงคั่น section) — ให้ทำโครงแถบเป็น component `<SectionBand tone="…">` ไว้ เปลี่ยนสีทีหลังได้ง่าย
- ระยะห่างระหว่างเนื้อหาเท่าเดิม: padding บน/ล่างของแถบ = ครึ่งหนึ่งของ margin เดิม (48–65px)
- **หัวข้อทุก section มีไฮไลต์เหลือง** `background: linear-gradient(transparent 58%, #FFC940 58%)` + `box-decoration-break: clone` (หัวข้อ 2 บรรทัดไฮไลต์ครบ) หัวข้อที่เคย 34px → 44px · ยกเว้น "การทำงานของผมในตอนนี้" (พื้นดำ มีคำเหลืองแล้ว) และ "ขอบคุณที่ให้ความสนใจ" (อยู่บนการ์ดเหลือง)
- **เลื่อนแบบแม่เหล็ก (scroll snap):**
  ```css
  html { scroll-snap-type: y proximity; }            /* proximity = ดูดเฉพาะตอนใกล้ ไม่บังคับ */
  .section-band { scroll-snap-align: center; }       /* section ที่เตี้ยกว่าจอ → ดูดมากลางจอ */
  .section-band.is-tall { scroll-snap-align: start; scroll-margin-top: 24px; } /* สูงกว่าจอ (งาน · รูป · โปรเจคจบ) → หัวข้อชิดบน */
  @media (max-width: 768px), (prefers-reduced-motion: reduce) { html { scroll-snap-type: none; } }
  ```
  คำนวณ `is-tall` จากความสูงจริง (ResizeObserver) ไม่ hardcode · ปก (จอ 1) ก็ snap start ได้

### 7.5 รูปจากงานจริง — จัดวางใหม่ ✅ **เจ้าของเลือกแบบ A แล้ว (27 ก.ย.)** — ไฟล์ `design/v8/V8PhotoA.dc.html` (ทั้ง 3 แท็บ) + `V8PhotoMobile.dc.html` (มือถือ) · B, C ไม่ใช้
ปัญหาเดิม: รูปวางกลางกล่อง 2 แถว เหลือที่ว่างขาวเยอะ ขนาดไม่เท่ากัน
**แบบ A — แถวเดียวเต็มกล่อง (justified row):** ทุกรูปในแท็บอยู่แถวเดียว **สูงเท่ากัน** กว้างตามสัดส่วนจริง (`ar` ใน PhotoWall.tsx) รวมกันเต็มความกว้างกล่องพอดี ไม่ครอป
```ts
const gap = 14;                       // ไอแพด 10
const h = (boxWidth - gap * (photos.length - 1)) / photos.reduce((s, p) => s + p.ar, 0);
// แต่ละรูป: width = h * p.ar, height = h, object-fit: cover, radius 12, border 1.5px #191816
// คำบรรยายใต้รูป 12.5px จุดสี #24A89A
```
ใช้ `ResizeObserver` วัด `boxWidth` · ได้สูง ≈ โรงงาน 270px / เสนอขาย 215px / ประชุม 235px ที่จอคอม — กล่องสูงใกล้กันทุกแท็บ สลับแล้วหน้าไม่กระโดด
**มือถือ:** ไม่ใช้ justified — ใช้ **ปัดทีละรูป** (สูง 300, กว้างตามสัดส่วน สูงสุด 330, `scroll-snap-type: x mandatory`) + จุดบอกลำดับ "1 / 6 · ปัดดูรูปถัดไป" · แท็บเลื่อนแนวนอนได้
แท็บยังเปลี่ยนเองทุก 6 วิ หยุดเมื่อชี้/แตะรูป
